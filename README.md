An old game project where two teams "Subjects" and "Guards" fight for control of a terminal placed in a facility. 

## Key systems
- Server-authoritative raycast weapon system
- Functioning shop system with server-authoritative item purchase checking
- Entity Component Systems-oriented game architecture. This architecture is not perfect as it has redundant functionality.
